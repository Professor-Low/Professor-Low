Core platform:

- [`Cerebro`](https://github.com/Professor-Low/Cerebro) – memory, autonomous agents, a real browser and your device mesh, running on your own machine
- [`Memory`](https://cerebro.life/compare) – conversations, corrections and goals persist across every session and are shared by every agent
- [`Agent Teams`](https://cerebro.life/#features) – coders, researchers and analysts work one repo in parallel, check their own output, and ship pull requests
- [`MCP Tools`](https://cerebro.life/docs/mcp-tools) – the tool layer that gives Claude, Codex and local models memory, browser control and orchestration

Apps and extensions:

- `Cerebro Desktop` – the full platform on web, desktop and mobile
- [`Cerebro Share`](https://share.cerebro.life) – publish web apps to a shareable link
- `Cerebro Glasses` – Cerebro on Even Realities G2 smart glasses
- [`Marketplace`](https://cerebro.life/market) – community capability packs, MCP servers and agents *(coming soon)*
- [`Cerebro Installer`](https://github.com/Professor-Low/Cerebro-Installer) – one-command setup
